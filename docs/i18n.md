# Internationalization

The Qt/QML UI uses English source strings with `qsTr()` and Qt Linguist
contexts. `locale/en_US/LC_MESSAGES/aerocore-browser.po` is the English
reference catalog: its `msgstr` values match the English `msgid` values, so it
also serves as a readable template. Translator catalogs are gettext PO files at
`locale/<locale>/LC_MESSAGES/aerocore-browser.po`; English is the `msgid` and
the target language is recorded in the PO header and `msgstr` values. CMake
discovers these files at configure time and builds one Qt QM catalog per PO.
When `msgfmt` is available, it also builds and installs matching MO catalogs
for gettext consumers.

## Add a language

1. Copy `locale/en_US/LC_MESSAGES/aerocore-browser.po` to
   `locale/<locale>/LC_MESSAGES/aerocore-browser.po`, using a locale such as
   `fr_FR` or `ja_JP` for `<locale>`.
2. Update the PO header's `Language` field and translate the `msgstr` entries.
   Keep `msgid` and `msgctxt` unchanged; the context is required to match Qt's
   QML translation lookup.
3. Reconfigure the build directory so CMake discovers the new catalog, then
   build normally. The resulting file is
   `build/translations/aerocore-browser_<locale>.qm` and is copied beside the
   executable or installed under `bin/translations`.
4. Set `language` in `config/distribution.json` to the locale (for example,
   `fr-FR`) to select it for that distribution. Without a configured language,
   the application uses the system locale. Runtime lookup tries the full locale
   first and then its base language; if no catalog exists, English source text
   remains visible.

The English reference catalog is used when the configured locale is `en-US`;
its translations match the source text. The existing Simplified Chinese catalog
continues to use `zh_CN`; a `zh-CN` distribution language selects it. Other
locales show English source text wherever their catalog has no translation.

## Refresh source strings

After configuring the project, run:

```sh
cmake --build build --target update-aerocore-browser-po
```

The target refreshes every discovered PO while preserving translations for
unchanged source messages. Review each catalog diff and complete new entries,
then rebuild. Add a new locale catalog before running this target so it is
included.
